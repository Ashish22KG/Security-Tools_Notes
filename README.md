# Security Tools Notes

A growing collection of practical, hands-on notes on cybersecurity and networking tools — built while preparing for interviews and hardening my own understanding of network defense, traffic analysis, and system security.

## About

I'm Ashish Gahukar, an IT Infrastructure & Security graduate (PGCP-ITISS, Sunbeam C-DAC ACTS) based in Pune, India, with a B.Tech in Computer Science & Engineering. This repo is where I document what I learn as I work through security tools one at a time — not just command syntax, but *where* to find each feature and *why* it matters during real analysis.

Each note is written to be a fast, practical reference: the kind of thing I'd want open in a second tab during a live investigation or a technical interview.

## Why This Repo Exists

- **Learning in public** — documenting tools as I learn them, in a structured, revisitable format.
- **Interview-ready reference** — quick recall of tool options, menu paths, and use cases without digging through scattered notes.
- **Portfolio piece** — a way for interviewers and hiring managers to see how I approach learning a new tool: systematically, with attention to *what* a feature does and *where* it lives.

## What You'll Find Here

Each tool gets its own notes file, generally covering:
- Core options/commands and what they do
- GUI locations / menu paths (for tools with a UI)
- Filtering and querying syntax
- Practical examples and common use cases
- Quick-reference tables for fast lookup

## Background

Some of what shows up in these notes is informed by hands-on project work, including a simulated multi-office enterprise network (pfSense, Active Directory, OpenVPN/Tailscale, Suricata IDS/IPS, and AWS/Docker deployment) built as part of my final-year cybersecurity portfolio project.

## Format

Notes are written in Markdown, organized as reference tables where possible, so information is scannable rather than buried in paragraphs.
